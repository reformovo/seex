# Seex 0.1.0b5

Seex 0.1.0b5 simplifies Viewer source management and prevents unintended source
removals. Cargo package `0.1.0-beta.5`, Python package `0.1.0b5`, and tag
`v0.1.0-beta.5` identify the same source.

## Install

```console
pip install seex==0.1.0b5
cargo add seex@0.1.0-beta.5
brew install reformovo/tap/seex-app
```

## Viewer

- Opening source management leaves the selection empty until a Source is
  selected. Removing a newly added Source clears the selection, preventing
  a subsequent removal from targeting a neighboring Source.
- Source lists display directory names and paths. Source aliases are assigned
  automatically; the dialog no longer requires editing an alias.

## Compatibility and known limits

The Python API, Parquet schema, and Workbench schema remain unchanged. The
[beta.4 compatibility and performance limits](0.1.0b4.md#compatibility-and-known-limits)
still apply, including elapsed-time Workbench compatibility, the default DuckDB
catalog's independent-reader/active-writer limitation, and large repeated-zoom
resource limits.

## Validation

Regression coverage checks explicit Source selection, removal without selecting
a neighbor, directory labels, and automatic aliases. Release qualification
requires the Rust and Python checks, package identity guard, and macOS app
bundle signature and icon checks described in the [release runbook](../releasing.md).
