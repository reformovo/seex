# Seex 0.1.0b3

Seex 0.1.0b3 improves the native macOS Viewer lifecycle. Cargo package
`0.1.0-beta.3`, Python package `0.1.0b3`, and tag `v0.1.0-beta.3` identify the
same source.

## Install

```console
pip install seex==0.1.0b3
cargo add seex@0.1.0-beta.3
brew install reformovo/tap/seex-app
```

## macOS Viewer lifecycle

- Closing the last Viewer window with the red close button keeps Seex running
  in the Dock, following the standard macOS document-app lifecycle.
- Clicking the Dock icon after closing the last window opens a new Viewer
  window in the existing process.
- `Command-Q` flushes pending Workbench persistence and exits the application.
- A quit request received while a window-close flush is pending is promoted to
  an application quit, avoiding an unresponsive Dock process.

The Viewer remains a native `Seex.app` bundle with its `Seex.icns` icon and an
ad-hoc signature. Direct GitHub downloads are not Apple-notarized and may
require one-time Gatekeeper approval. The Homebrew Formula builds the app from
the immutable release source and publishes a bottle through GitHub Packages.

All storage, typed API, CLI JSON, and Parquet compatibility qualifications from
0.1.0b2 remain unchanged.
