# Seex 0.1.0b2

Seex 0.1.0b2 republishes the second beta with a native macOS application
bundle. Cargo package `0.1.0-beta.2`, Python package `0.1.0b2`, and tag
`v0.1.0-beta.2` identify the same source.

## Install

```console
pip install seex==0.1.0b2
cargo add seex@0.1.0-beta.2
brew install reformovo/tap/seex-app
```

## macOS Viewer packaging

- The Viewer is packaged as `Seex.app` with its native `Seex.icns` icon.
- The complete app bundle receives a local ad-hoc signature before packaging.
- GitHub releases contain `Seex-macos-aarch64.zip` and its SHA-256 checksum.
- The Homebrew Formula builds the same app bundle from the immutable release
  source and publishes a bottle through GitHub Packages.
- The Formula exposes both the app bundle and the `seex-app` command-line
  entrypoint without requiring an Apple Developer ID.

Direct GitHub downloads are not Apple-notarized and may require one-time
Gatekeeper approval. Homebrew Formula installations do not carry the Cask
quarantine attribute.

All storage, typed API, CLI JSON, and Parquet compatibility qualifications from
0.1.0b1 remain unchanged.
