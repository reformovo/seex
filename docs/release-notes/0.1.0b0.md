# Seex 0.1.0b0

Seex 0.1.0b0 is the first beta under the Seex name. Install it with
`pip install seex==0.1.0b0`, import it as `seex`, and use the `seex` command.

This release is a hard identity reset from PulseOn. It does not import the old
Python package, inspect `.pulseon`, read old environment variables, migrate old
catalog application tables, or restore old desktop workbench documents. Legacy
state is left untouched. The product-owned Parquet schema remains the open data
compatibility boundary when explicitly configured.

The desktop binary is named `seex-app` and is distributed independently from
the SDK wheel. `seex app [PROJECT_PATH]` launches that binary when it is
available on `PATH`.
