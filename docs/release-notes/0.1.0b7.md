# Seex 0.1.0b7

Seex 0.1.0b7 is a packaging release over 0.1.0b6. It restores Homebrew source
builds after `cargo-bundle` 0.12 changed its macOS metadata schema, and it carries
the DuckDB 2.0.0 LTS engine and platform coverage from 0.1.0b6 unchanged. Cargo
package `0.1.0-beta.7`, Python package `0.1.0b7`, and tag `v0.1.0-beta.7`
identify the same source.

## Install

```console
pip install seex==0.1.0b7
cargo add seex@0.1.0-beta.7
brew install reformovo/tap/seex-app
```

## Packaging

- `crates/seex-app/Cargo.toml` now uses the cargo-bundle 0.12 schema:
  `[package.metadata.bundle.osx] minimum_system_version = "10.15.7"`.
- The Viewer build installs cargo-bundle 0.12.0, matching Homebrew's current
  formula. Source builds from the release tarball work again, and tap bottles
  are rebuilt from this tag.
- Everything else is unchanged from 0.1.0b6: local-only SQLite catalog,
  append-only v5 store, Parquet compatibility boundary, and DuckDB 2.0 platform
  coverage (Linux amd64/arm64 glibc and musl, macOS 10.13+, Windows amd64/arm64).

## Breaking changes

None beyond 0.1.0b6; the store format and public APIs are unchanged.

## Verification

The release guard checks the Cargo, Python, Viewer, and tag identities. Local and
CI gates run `cargo test --release`, ruff, and pyright; see
[the upgrade notes](../reference/duckdb-2.0-upgrade.md).
